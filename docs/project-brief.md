# ByteBoard Project Brief

## Project purpose

ByteBoard is a community-driven technology and startup news platform where users can submit news stories, discover developments, discuss posts, and rank stories through votes.

This repository is a Code Institute Backend Development Milestone Project. It is intended to demonstrate relational data modelling and full-stack development with Django while keeping ownership, moderation, accessibility, and data integrity central to the design.

## External-user goal

Visitors and registered members need a focused place to:

- browse current technology and startup stories;
- find stories through categories and search;
- identify each story's author and publication date;
- register and sign in;
- submit, edit, and delete their own stories;
- discuss stories and manage their own comments; and
- upvote or downvote stories to help the community rank them.

## Site-owner goal

The site owner wants to build a useful technology discussion community, encourage relevant submissions, organise stories by topic, moderate categories and contributions, and protect both content ownership and relational data integrity.

## Target audience

ByteBoard is planned for technology professionals, founders, developers, students, investors, enthusiasts, and readers who want a concise community-curated view of technology and startup news.

## Initial content scope

The planned categories are:

- Artificial Intelligence
- Startups
- Software Development
- Cybersecurity
- Gadgets
- Fintech

## Phase 1 boundaries

Phase 1 establishes planning, documentation, data models, migrations, Django Admin configuration, and automated model/admin tests. Authentication pages, post CRUD views, templates, comment and voting interfaces, search, visual styling, and deployment are deliberately deferred to later phases.

## Success criteria

Phase 1 is successful when the intended experience is documented, the domain relationships and constraints are represented in tested Django models, the models are manageable through Django Admin, migrations are complete, and the repository contains an honest starting README and roadmap without claiming unfinished features.
